# 모두의 성장 2.2 — 기업회원 대시보드 및 회사 자료실

이번 단계는 기업회원의 회사 자료 등록·관리 기능을 추가합니다.

## 포함 기능
- 기업회원 전용 `회사 자료실` 메뉴
- 회사소개서, 브로셔, 제품 카탈로그, 인증·특허, 기술자료 업로드
- 자료 제목·분류·설명 입력
- 열람 범위: 기업 내부용 / 비즈니스파트너 공개
- 공개 상태: 임시 보관 / 게시
- 업로드 자료 목록, 파일 열기(60초 서명 URL), 삭제
- 파일당 최대 20MB, PDF·Office 문서·JPG·PNG·WEBP 지원
- 비즈니스파트너에게 공개된 자료는 다음 단계에서 파트너 자료실과 연결할 수 있도록 권한 구조를 준비

## GitHub 업로드
1. ZIP 압축을 풉니다.
2. 기존 `modu-growth` 저장소의 `main` 브랜치 루트에 포함 파일을 업로드해 덮어씁니다.
3. `config.js`는 현재 사용 중인 Supabase URL과 publishable/anon key가 든 파일을 유지합니다. 서비스 키는 절대 사용하지 않습니다.
4. GitHub Pages 배포 후 Ctrl+F5로 새로고침합니다.

## Supabase 설정 — 반드시 검토 후 1회 적용
`supabase-company-library-migration.sql`은 기존 `profiles`, `offers`, 회원 계정을 삭제하지 않는 추가 마이그레이션입니다. 기존 DB 백업 후 Supabase SQL Editor에서 이 파일만 검토·실행합니다.

이 SQL은 `company_documents` 테이블, 비공개 `company-library` Storage bucket, Storage와 테이블 RLS 정책을 추가합니다. 공개 bucket이 아니며 파일은 권한이 확인된 로그인 사용자만 접근합니다. 파트너 공개/게시 상태인 파일만 향후 비즈니스파트너 열람 대상으로 허용합니다.

**주의:** 기존 `supabase-schema.sql` 또는 `supabase-schema-reference-do-not-run.sql`은 다시 실행하지 마세요. SQL 실행 전 현재 `profiles.role` 값이 `company`, `partner`, `admin`인지 확인하세요. 프로젝트의 기존 정책/테이블 상태가 문서와 다르면 실행을 멈추고 먼저 검토해야 합니다.

## 테스트 순서
1. 기업회원 계정으로 로그인합니다.
2. 대시보드의 `회사 자료실` 메뉴를 확인합니다.
3. 테스트용 PDF 하나를 `기업 내부용 / 임시 보관`으로 업로드합니다.
4. 목록에서 열기와 삭제를 확인합니다.
5. 두 번째 테스트 파일을 `비즈니스파트너 공개 / 게시`로 등록합니다. 현재 버전에서는 공개 설정만 저장하며 파트너 자료 열람 화면은 다음 단계에서 구현합니다.
6. 비즈니스파트너 계정에서는 회사 자료실 메뉴가 보이지 않는 것이 정상입니다.

## 현재 단계의 범위와 한계
- 회사 프로필의 상세 항목/브랜드 정보 편집은 기존 내 정보 기능을 사용합니다.
- 파트너용 자료 탐색, 영업 신청, 고객 CRM, 계약·매출·수수료·정산은 다음 개발 단계입니다.
- 파일을 공개로 설정했다고 외부 공개 URL이 생성되는 것은 아닙니다. 비공개 Storage와 RLS, 짧은 만료시간의 signed URL을 사용합니다.
- 실제 Supabase 프로젝트에서 SQL 적용 및 업로드/권한 테스트는 아직 실행하지 않았습니다.

## 2.3 기업회원 사업자 정보

기업회원의 내 정보 관리에 다음 항목을 추가했습니다.
- 사업자 유형(법인사업자/개인사업자)
- 사업자등록번호 10자리
- 법인사업자 전용 법인등록번호 13자리
- 대표자명, 개업연월일, 업태, 종목, 사업장 주소
- 회사 대표전화, 홈페이지, 공식 이메일, 담당자 정보

`supabase-company-profile-migration.sql`은 기존 `profiles` 테이블에 필요한 컬럼과 검증 제약조건을 추가하는 증분 마이그레이션입니다. 기존 회원 데이터와 로그인은 삭제하지 않습니다. 기존 전체 스키마 SQL을 재실행하지 마세요.

`config.js`는 기존 프로젝트의 Supabase 연결 설정을 유지해야 하므로 GitHub 업로드 시 덮어쓰지 마세요.
