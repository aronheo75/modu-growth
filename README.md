# 모두의 성장 2.1 — 회원 명칭 통일 업데이트

이번 파일은 현재 적용된 연락처 입력란은 그대로 두고, 화면에 표시되는 회원 유형 명칭만 통일한 버전입니다.

- 회원가입 연락처 입력란 유지
- 화면 문구의 “파트너”, “영업파트너”를 “비즈니스파트너”로 통일
- 내부 Supabase 역할 코드 `partner`는 기존 계정 호환을 위해 변경하지 않음
- 기업 자료 업로드 기능은 포함하지 않음

## GitHub 반영
1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소 루트에 파일을 업로드하고 덮어씁니다.
3. `config.js`는 현재 저장소의 기존 Supabase 연결 설정을 그대로 보존합니다.
4. GitHub Pages 배포가 완료되면 새로고침 후 홈페이지와 회원가입 화면의 명칭을 확인합니다.

이번 작업은 화면 문구 변경만을 위한 업데이트입니다. 연락처 저장을 위한 SQL을 새로 실행할 필요는 없습니다. 기존에 적용한 Supabase 설정은 유지하세요. `supabase-schema-reference-do-not-run.sql`은 실행하지 마세요.
