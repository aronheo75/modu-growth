# 모두의 성장 2.4 통합본

기업회원 기본정보 관리(2.3)와 상품·서비스 등록 개선(2.4)을 한 폴더로 통합한 GitHub Pages 배포 패키지입니다.

## 포함 기능
- 기존 홈페이지, Supabase 로그인/회원 구분 및 기업회원 대시보드
- 기업회원 사업자 정보: 법인/개인사업자, 사업자등록번호, 법인등록번호, 대표자, 개업일, 업태/종목, 주소, 홈페이지, 공식 이메일, 연락처
- 회사 자료실 UI 및 기존 연동 코드
- 상품·서비스 등록: 기본정보, 수익모델(일회성/정기·반복/혼합), 가격 방식/가격, 주요 고객층, 공급 가능 지역, 핵심 경쟁력
- 신규 상품은 기존 offers 테이블의 pending 상태로 신청되어 관리자 검토 전 자동 공개되지 않는 흐름

## GitHub 업로드
`GITHUB_UPLOAD_GUIDE.txt`를 따르세요. 압축 해제 폴더 안의 모든 파일을 기존 저장소 main 루트에 한 번에 업로드할 수 있습니다. 같은 이름 파일은 교체하고 새 파일은 추가합니다. GitHub 웹 업로드는 패키지에 없는 기존 파일을 자동 삭제하지 않습니다.

`config.js`는 현재 프로젝트의 Supabase URL과 publishable key를 포함한 기존 설정 파일로 패키지에 보존했습니다. secret/service_role key는 포함하지 않습니다.

## Supabase SQL
- `supabase-company-profile-migration.sql`: 2.3 기업회원 사업자정보 컬럼 추가. 이미 성공적으로 실행한 경우 재실행하지 마세요.
- `supabase-product-registration-migration.sql`: 2.4 상품·서비스 영업정보 컬럼 추가. 아직 적용하지 않았다면 백업 및 SQL 검토 후 한 번 실행하세요.
- `supabase-company-library-migration.sql`: 회사 자료실 설정이 아직 안 된 경우에만 별도 검토 후 적용하세요.
- `supabase-schema-reference-do-not-run.sql`: 참고용 전체 스키마 파일이며 실행 금지.

전체 스키마 재실행, 회원/상품 데이터 초기화는 하지 않습니다.

## 범위 및 다음 단계
현재 2.4는 기업회원 기본정보와 상품등록 정보 확장까지 포함합니다. 상품 이미지 첨부, 관리자 승인 전용 화면, 파트너용 승인상품 탐색, 협약조건/수수료/정산 기능은 후속 단계에서 별도 구현해야 합니다.
