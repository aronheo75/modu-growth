# 모두의 성장 2.1 — 연락처 및 회원 명칭 업데이트

이번 버전은 기존 2.0 최종 홈페이지를 바탕으로 아래 두 가지만 반영했습니다.

1. 기업회원·비즈니스파트너 회원가입 항목에 연락처 입력란 추가
2. 화면에 표시되는 “영업파트너” 명칭을 “비즈니스파트너”로 통일

회원 역할의 내부 코드 `partner`는 기존 계정과의 호환성을 위해 변경하지 않았습니다. 회사 브로셔·카탈로그 업로드/자료실 기능은 이번 버전에 포함하지 않았습니다.

## GitHub 반영
1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소의 루트에 압축 안의 파일을 업로드하고 덮어씁니다.
3. 기존 Supabase 연결 정보가 담긴 `config.js`는 그대로 유지합니다. ZIP의 `config.js`도 동일한 기존 설정을 담고 있지만, 본인 저장소의 설정 파일을 보존하는 것이 안전합니다.

## Supabase 연락처 저장 설정
회원가입 화면에서 받은 연락처를 `profiles.phone`에 자동 저장하려면 `supabase-migration-contact-only.sql`을 Supabase SQL Editor에서 한 번 실행해야 합니다. 이 SQL은 기존 `handle_new_user` 트리거 함수를 연락처 저장까지 하도록 교체하며, 기존 회원/상품/정책/테이블을 삭제하지 않습니다. 기존 스키마에 `profiles.phone` 컬럼이 있는 구성을 전제로 합니다.

`supabase-schema-reference-do-not-run.sql`은 참고용입니다. 기존 데이터베이스에 다시 실행하지 마세요.

## 확인 항목
- 기업회원 가입: 이름/담당자명, 연락처, 이메일, 비밀번호 입력
- 비즈니스파트너 가입: 동일 항목 입력
- Supabase `public.profiles`에서 신규 가입자의 `phone` 값 확인
- 화면 전체에서 “영업파트너” 문구가 남아 있지 않은지 확인

실제 GitHub 배포 및 실계정 가입 테스트는 이 패키지 생성 단계에서는 수행하지 않았습니다.
