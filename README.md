# 모두의 성장 2.0

기업과 비즈니스 파트너를 연결하는 동반 성장 플랫폼의 프런트엔드 통합 배포본입니다.

## 2.0 디자인 방향
- 딥 네이비 기반의 프리미엄 기업형 메인 디자인
- 라임·시안 포인트 컬러와 기업·파트너·시장 연결 그래픽
- 반응형 상단 메뉴 및 모바일 내비게이션
- 플랫폼 소개, 이용 절차, 핵심 서비스, 1차 목표(기업 50개사·파트너 500명), 회원별 업무공간
- 기존 로그인·회원가입·프로필·기업 상품/서비스 등록 흐름 유지

## 포함 기능과 제한
- Supabase 이메일 회원가입/로그인
- profiles에서 본인 프로필 조회 및 수정
- 기업회원의 offers 등록 및 본인 등록 상품 조회
- 파트너 계정의 상품 조회는 현재 권한 정책에 따라 제한될 수 있습니다.
- 관리자 승인, 기업 간 매칭, 자료 파일 업로드/다운로드, 거래 계약 및 정산은 이 패키지에서 완성된 운영 기능으로 제공하지 않습니다. 화면에 보이는 목표 수치는 목표치이며 실적이 아닙니다.

## 배포 전 필수 확인
1. 현재 GitHub 저장소 파일을 먼저 백업하세요.
2. ZIP 압축을 푼 뒤 파일 8개를 저장소 최상위에 한꺼번에 업로드하세요.
3. `config.js`는 현재 Supabase 프로젝트의 기존 URL 및 publishable/anon key를 보존한 파일입니다. 이 파일을 다른 설정으로 교체하지 마세요.
4. SQL 파일은 참고용입니다. 기존 데이터베이스에 실행하지 마세요.
5. GitHub Pages 배포 완료 후 브라우저에서 강력 새로고침(Ctrl+F5)을 하세요.

## 보안
브라우저에 노출되는 키는 Supabase publishable/anon key만 사용해야 합니다. `service_role` 또는 secret key를 절대 `config.js`에 넣지 마세요. 실제 데이터 접근은 Supabase RLS 정책으로 보호되어야 합니다.
