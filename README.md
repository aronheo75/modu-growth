# 모두의 성장 2.5 통합 패키지

2.4 기업회원 기능을 바탕으로 상품 등록 데이터와 관리자 승인 흐름을 통합했습니다.

- 기업회원: 회사정보 관리, 상품·서비스 등록 및 본인 상품 조회
- 관리자: 상품 검토, 승인 및 공개, 반려, 판매 보류
- 비즈니스파트너: 승인 완료(active) 상품 조회
- 보안: 신규 기업 상품은 DB 트리거가 pending으로 강제하며, 비관리자의 상태 변경을 차단

설치 절차는 `README-2.5-INSTALL.txt`를 확인하세요.

기존 `profiles`, `offers` 데이터와 Supabase 인증 계정은 삭제하거나 초기화하지 않습니다.
