모두의 성장 3.0 통합 업데이트 설치 안내

포함 범위
- 기업회원: 기존 기업정보·상품·자료실 유지, 상품별 제휴/협약 신청 및 심사현황
- 비즈니스 파트너: 전문분야·영업지역·경력 프로필, 승인 상품 탐색, 영업 참여 신청, 고객/영업건 등록 및 조회
- 관리자: 제휴조건 검토, 기업 제안 총 수수료율에 대한 파트너 지급률/플랫폼 운영률 확정, 파트너 신청 승인, 영업실적·수동 정산상태 관리

설치 순서
1. GitHub 저장소의 기존 파일을 삭제하지 말고, ZIP 안 파일을 저장소 루트에 업로드하며 같은 이름 파일만 교체합니다.
2. 현재 저장소의 config.js는 반드시 기존 파일을 유지합니다. 브라우저용 Supabase publishable/anon key만 사용합니다.
3. Supabase 대시보드에서 SQL Editor를 열고 supabase-modoo-growth-3.0-migration.sql 전체를 검토한 뒤 실행합니다.
4. 기존 2.x의 회사 프로필/자료실/상품 확장 SQL이 이미 적용되어 있어야 합니다. 이 SQL은 그 테이블들을 삭제하지 않는 추가형 마이그레이션입니다.
5. GitHub Pages 배포 완료 후 사이트에서 기업/파트너/관리자 계정으로 각각 로그인해 기능을 확인합니다.

중요
- 실제 운영 전 Supabase 백업을 권장합니다.
- 관리자 계정의 profiles.role='admin' 설정은 기존의 신뢰된 관리자 절차로만 수행해야 합니다. 일반 회원가입 화면에서 관리자 역할을 선택할 수 없습니다.
- 파트너 영업 참여는 관리자 승인 후 영업 건 등록이 가능합니다.
- 제휴 승인 시 파트너 지급률 + 플랫폼 운영률 합계는 기업이 제안한 전체 수수료율과 같아야 합니다.
- 승인된 협약 조건을 수정하면 이전 버전이 platform_agreement_history에 보존됩니다.
- 정산 기능은 내부 상태 기록 및 관리자 수동 확인입니다. 실제 계좌이체/PG 결제는 연동되어 있지 않습니다.
- 기업 상품 공개 승인(offers.status) 권한은 기존 2.5 상품 관리자 SQL의 트리거 보호를 전제로 합니다.
- 오류가 발생하면 기존 데이터를 삭제하거나 테이블을 초기화하지 말고 오류 메시지와 화면을 먼저 공유해 주세요.
