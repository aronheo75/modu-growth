모두의 성장 2.1 GitHub 수정 순서

1) ZIP 압축을 풉니다.
2) 기존 GitHub 저장소의 루트에 압축 안의 파일을 업로드합니다.
3) 기존 config.js는 현재 저장소의 연결 설정을 보존합니다.
4) Supabase SQL Editor에서 supabase-migration-contact-only.sql을 한 번 실행합니다.
5) GitHub Pages 배포 완료 후 회원가입을 테스트합니다.

회원가입 항목: 이름/회사 담당자명 + 연락처 + 이메일 + 비밀번호
회원 유형 표기: 기업회원 / 비즈니스파트너

주의
- 기존 Supabase 프로젝트를 새로 만들거나 기존 DB를 초기화하지 마세요.
- supabase-schema-reference-do-not-run.sql은 실행하지 마세요.
- 이번 버전에는 기업 브로셔/카탈로그 업로드 기능이 포함되어 있지 않습니다.
- 내부 role 값 partner는 기존 데이터 호환을 위해 그대로 유지합니다.
