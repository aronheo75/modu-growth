모두의 성장 2.5 업데이트

1. 기존 2.4 기업회원 정보관리 및 상품·서비스 등록 화면 유지
2. 상품 수익모델, 가격방식, 가격, 고객층, 공급지역, 핵심 경쟁력 데이터 항목 통합
3. 신규 기업 상품은 서버 트리거에서 pending(관리자 검토 대기)으로 강제
4. 기업회원이 상품 상태를 active/rejected/paused로 임의 변경하지 못하도록 서버 측 차단
5. 관리자 전용 운영 관리 화면에 상품 승인·반려·판매 보류 기능 추가
6. 비즈니스파트너 상품 목록은 active(승인 완료) 상품만 조회하도록 화면 흐름 연결
7. 기존 회원, profiles, offers 데이터 삭제/초기화 없음

주의:
- config.js는 기존 Supabase URL 및 publishable/anon key를 유지한 파일입니다. 별도 수정하지 마세요.
- Supabase에는 supabase-product-admin-migration.sql만 이번 업데이트용으로 실행합니다.
- 이미 실행한 사업자정보 migration은 다시 실행할 필요가 없습니다.
- 관리자 계정은 기존 관리자 지정 절차로 role='admin'이 부여된 계정만 사용합니다.
