모두의 성장 2.0 통합 업데이트 안내

1. ZIP 압축을 풉니다.
2. GitHub 저장소 aronheo75/modu-growth의 main 브랜치 최상위(root)에서 Add file > Upload files를 선택합니다.
3. index.html, style.css, app.js, config.js, config.example.js, README.md, GITHUB_UPLOAD_GUIDE.txt를 업로드해 기존 파일과 교체합니다.
4. Commit changes 후 GitHub Pages 배포를 기다립니다.
5. https://aronheo75.github.io/modu-growth/ 에서 Ctrl+F5로 새로고침합니다.

중요: 기존 Supabase 회원과 데이터는 삭제하지 않습니다. supabase-schema.sql은 재실행하지 마세요.
기업자료실을 활성화하려면 먼저 Supabase 백업을 만든 뒤 supabase-migration-documents.sql을 검토하고 별도로 실행해야 합니다. 적용 후 기업 계정으로 파일 업로드, 파트너 계정으로 공개 자료 다운로드, 비공개 자료 접근 차단을 각각 테스트하세요.
config.js에는 브라우저 공개용 Publishable Key만 사용합니다. service_role/secret key를 절대 넣지 마세요.
