모두의 성장 2.0 | 전체 통합 업로드 안내

1) 먼저 현재 GitHub 저장소를 백업합니다.
   https://github.com/aronheo75/modu-growth

2) 아래 통합 ZIP을 PC에 내려받고 압축을 풉니다.

3) GitHub 저장소의 main 브랜치에서 Add file > Upload files를 선택합니다.

4) 압축을 푼 폴더의 다음 파일 8개를 한꺼번에 업로드합니다.
   - index.html
   - style.css
   - app.js
   - config.js
   - config.example.js
   - README.md
   - GITHUB_UPLOAD_GUIDE.txt
   - supabase-schema-reference-do-not-run.sql

5) 파일 교체 목록을 확인한 뒤 Commit changes를 누릅니다.

6) GitHub Pages 배포가 완료되면 아래 주소를 엽니다.
   https://aronheo75.github.io/modu-growth/
   Ctrl + F5로 강력 새로고침합니다.

중요 사항
- config.js에는 기존 Supabase 프로젝트 URL과 공개용 publishable/anon key가 보존되어 있습니다. 삭제하거나 임의의 값으로 바꾸지 마세요.
- service_role/secret key는 절대 웹 파일에 넣지 마세요.
- supabase-schema-reference-do-not-run.sql은 참고용입니다. 실행하지 마세요.
- 기존 Supabase 프로젝트, 테이블, 회원, 자료를 삭제하거나 초기화하지 마세요.
- 운영 배포 전에 기존 저장소 전체를 ZIP으로 백업하세요.
- 회원가입/로그인/프로필/상품등록은 실제 Supabase 계정으로 배포 후 별도 점검이 필요합니다.
