모두의 성장 3.0 GitHub 통합 업로드

1) 기존 GitHub 저장소를 백업합니다.
2) ZIP을 풀고 압축 안의 파일을 저장소 최상위 폴더에 업로드합니다.
3) 동일 파일명은 교체합니다. ZIP에 없는 기존 파일은 삭제하지 않습니다.
4) config.js는 현재 프로젝트의 Supabase URL/Publishable(anon) key 설정을 확인하고 유지합니다. Secret/service_role key를 넣지 않습니다.
5) GitHub Actions 배포가 완료되면 홈페이지 접속과 기업/파트너/관리자 계정별 메뉴를 확인합니다.
6) Supabase SQL은 설치 안내서의 순서와 기존 적용 여부를 확인한 뒤 필요한 것만 실행합니다.
