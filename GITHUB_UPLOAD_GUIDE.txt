모두의 성장 2.0 전체 통합 업로드 안내

[업로드 대상]
ZIP 압축을 푼 뒤 아래 파일을 기존 GitHub 저장소의 최상위(루트)에 모두 업로드하고 같은 이름의 파일을 교체합니다.
- index.html
- style.css
- app.js
- config.js
- config.example.js
- README.md
- GITHUB_UPLOAD_GUIDE.txt
- supabase-schema-reference-do-not-run.sql

[GitHub 웹사이트에서 진행]
1. https://github.com/aronheo75/modu-growth 접속
2. Add file > Upload files 선택
3. 압축을 푼 폴더 안의 파일 8개를 한 번에 드래그해 업로드
4. 기존 파일과 이름이 같은 경우 교체되는지 확인
5. Commit changes 실행
6. Actions 또는 Pages 배포가 완료될 때까지 기다림
7. https://aronheo75.github.io/modu-growth/ 접속 후 Ctrl+F5 강력 새로고침

[중요]
- config.js는 기존 Supabase 프로젝트 설정이 보존된 파일입니다. 다른 파일로 덮어쓰거나 비우지 마세요.
- SQL 파일은 구조 참고용이며 실행하지 마세요.
- 기존 Supabase 프로젝트, 테이블, 회원 데이터는 삭제하거나 초기화하지 마세요.
- service_role/secret key를 웹 파일에 추가하지 마세요.
- 운영 배포 전 현재 저장소 파일을 ZIP으로 백업하세요.
