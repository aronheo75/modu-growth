모두의 성장 2.3 업로드 안내

1. ZIP 파일 압축을 해제합니다.
2. 압축 해제한 파일을 기존 GitHub 저장소(modu-growth) 루트에 업로드하고 기존 파일을 덮어씁니다.
3. config.js는 현재 Supabase 연결값이 들어 있으므로 덮어쓰지 말고 기존 파일을 유지합니다.
4. Supabase SQL Editor에서 supabase-company-profile-migration.sql 내용을 검토한 뒤 실행합니다.
   - profiles에 기업 사업자 정보 컬럼만 추가합니다.
   - 기존 회원, 로그인, profiles 기존 값, 상품 데이터는 삭제하지 않습니다.
   - 기존 schema SQL은 재실행하지 마세요.
5. GitHub Pages 배포 완료 후 사이트에서 Ctrl+F5로 새로고침합니다.
6. 기업회원 로그인 → 내 정보 → 정보 수정에서 사업자 유형과 정보를 입력하고 저장합니다.

법인사업자: 법인등록번호 13자리 입력 필요
개인사업자: 법인등록번호 항목은 표시되지 않습니다.
사업자등록번호는 숫자 10자리로 저장되며, 같은 번호의 중복 등록은 차단됩니다.

주의:
- config.js의 기존 Supabase URL과 publishable/anon key를 보존하세요.
- service_role 또는 secret key를 브라우저 파일에 넣지 마세요.
- 이번 SQL은 기업 기본정보 컬럼 추가용입니다. 기존 회사 자료실 기능은 별도 2.2 자료실 마이그레이션이 실행되어 있어야 정상 작동합니다.
